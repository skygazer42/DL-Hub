# Multimodal Reasoning

Toy-first multimodal reasoning families for local experimentation.

Families in this package:

- `vqa_reasoner`
- `chain_reasoner`
- `tool_reasoner`
- `memory_reasoner`
- `grounded_reasoner`
- `program_reasoner`
- `transformer_reasoner`
- `retrieval_reasoner`
- `prompt_reasoner`
- `mamba_reasoner`

Each family exposes `build_<family>_reasoner(...)` with `tiny`, `small`, and `base` variants.

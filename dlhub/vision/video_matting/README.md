# Video Matting

Compact-first video matting families for local experimentation.

Families in this package:

- `dim_vmatte`
- `fba_vmatte`
- `rvm_baseline`
- `gca_vmatte`
- `tcvomatting`
- `memory_vmatte`
- `transformer_vmatte`
- `flow_vmatte`
- `prompt_vmatte`
- `mamba_vmatte`

Each family exposes `build_<family>_video_matter(...)` with `tiny`, `small`, and `base` variants.

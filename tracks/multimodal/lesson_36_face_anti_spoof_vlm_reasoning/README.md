# Lesson 36: Face Anti-Spoof VLM Reasoning

This lesson pairs a compact synthetic face image with a short textual authenticity cue and trains a
tiny multimodal classifier to predict whether the face is authentic or spoofed.

## What It Teaches

- synthetic live-vs-spoof face generation without external data
- lightweight fusion of vision features and short text prompts
- binary multimodal reasoning for authenticity classification

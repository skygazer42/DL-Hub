# Foundations 轨（基础）

这条轨道的目标是：让你真正掌握 **“训练一个模型”** 的核心能力，而不是只会跑脚本。

核心主题包括：

- Tensor / shape / broadcasting（张量与形状直觉）
- autograd（反向传播发生了什么）
- 训练循环（loss、优化器、学习率、过拟合、正则化）
- 可复现与实验习惯（seed、device、输出目录、记录指标）

## Lessons

- `lesson_01_tensors/`：张量与 shape 直觉（无训练）
- `lesson_02_linear_regression_autograd/`：线性回归 + autograd（最小训练闭环，纯合成数据）
